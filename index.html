Комната: — хост
Игроки сталкиваются физически
Экспериментальный P2P-мультиплеер (через сеть PeerJS, без своего сервера — подходит для запуска на GitHub Pages). Первый, кто вводит название комнаты, становится хостом; все остальные с тем же названием подключаются к нему. Все карты в комнате генерируются из одного набора — это гарантирует, что платформы и препятствия у всех игроков совпадают. Не более нескольких игроков в одной комнате — стабильность P2P-соединений ограничена.
